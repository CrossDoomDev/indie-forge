# Инди Кузница — главная страница

Статическая вёрстка по предоставленному скриншоту. Без серверной логики, API и базы данных.

## Открыть
Откройте `index.html` двойным щелчком. Все шрифты, изображения и скрипты находятся внутри проекта.

Для локального просмотра через HTTP:
```powershell
cd "D:\Codex Projects\indie-forge"
npm start
```
Адрес: http://127.0.0.1:5173. Node.js используется только как локальная раздача статических файлов.

## Файлы
- `index.html` — разметка главной страницы.
- `styles.css` — сетка, цвета, типографика, адаптация.
- `app.js` — поиск по видимым материалам, Ctrl+K, раскрывающиеся панели, чекбоксы и мобильное меню.
- `assets/` — семь сгенерированных иллюстраций, локальный Roboto и favicon.
- `assets/generation-prompts.json` — точные промпты иллюстраций; использован встроенный image_gen.
- `verification/` — скриншоты браузерной проверки.

Основной размер сравнения: 1586 × 902 px, то есть содержимое исходного скриншота без верхней рамки браузера. Иллюстрации воссозданы генерацией, поэтому художественные детали отличаются от исходных. Данные профиля и прогресса воспроизводят скриншот. Состояние заданий меняется только до перезагрузки страницы. Остальные разделы будут реализованы по следующим макетам; их кнопки сейчас показывают уведомление.

## Проверка
При запущенном `npm start`:
```powershell
npm install
npm run verify
```
Нужен установленный Google Chrome. Проверяются загрузка ресурсов, отсутствие ошибок и горизонтального переполнения на шести ширинах, поиск, клавиатурное сокращение, задания, уведомления, кнопки будущих разделов и мобильное меню.
