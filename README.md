# Инди Кузница

Статический сайт с главной страницей, разделом «Древо мастерства», титульными страницами курсов и встроенным редактором уроков. Каталог технологий, две ветки курсов, поиск, фильтры и ручное управление данными работают без сборки. Серверное хранение и авторизация ещё не подключены.

## Открыть
Для уроков и встроенного редактора запустите локальный HTTP-сервер. Все шрифты, изображения и скрипты находятся внутри проекта.

Для локального просмотра через HTTP:
```powershell
cd "D:\Codex Projects\indie-forge"
npm start
```
Адрес: http://127.0.0.1:5173. Node.js используется только как локальная раздача статических файлов.

## Файлы
- `index.html` — разметка главной страницы.
- `styles.css` — сетка, цвета, типографика, адаптация.
- `app.js` — поиск по видимым материалам, Ctrl+K, раскрывающиеся панели, чекбоксы и мобильное меню.
- `assets/` — семь иллюстраций WebP Lossless, векторные SVG, локальный Roboto и favicon.
- `assets/generation-prompts.json` — точные промпты иллюстраций; использован встроенный image_gen.
- `verification/` — скриншоты браузерной проверки.

Основной размер сравнения: 1586 × 902 px, то есть содержимое исходного скриншота без верхней рамки браузера. Иллюстрации воссозданы генерацией, поэтому художественные детали отличаются от исходных. Данные профиля и прогресса воспроизводят скриншот. Состояние заданий меняется только до перезагрузки страницы. В разделе «Древо мастерства» работают каталог технологий, основные и прикладные курсы. Остальные разделы будут реализованы по следующим макетам; их кнопки сейчас показывают уведомление.

## Проверка
При запущенном `npm start`:
```powershell
npm install
npm run verify
```
Нужен установленный Google Chrome. Проверяются загрузка ресурсов, отсутствие ошибок и горизонтального переполнения на шести ширинах, поиск, клавиатурное сокращение, задания, уведомления, кнопки будущих разделов и мобильное меню.


## Древо мастерства

Откройте пункт «Древо мастерства» в левой панели или адрес `#/mastery`. Blender и Aseprite представлены разными технологиями. Каталог отображается сеткой и списком. При выборе технологии открывается её описание с изображением; «Начать изучать» переводит к основным курсам с переключением на прикладные. Подробный текст редактируется в поле «О технологии — подробное описание».

В режиме «Администратор» на карточках видны статусы публикации, меню ⋯ и значок перетаскивания. Соседние карточки раздвигаются во время переноса, свободное место показывает точную позицию вставки. Новые записи создаются скрытыми; в режиме «Ученик» черновики не отображаются. Технология открывается одним кликом по всей карточке.

Кнопка «Управление каталогом» позволяет добавлять и редактировать технологии и курсы, менять ветку и порядок, загружать изображения и иконки, скрывать и удалять записи, импортировать и экспортировать JSON. Под выбором изображения показаны рекомендуемые и фактические размеры; обложки сохраняют пропорции и отображаются целиком. Формы сохраняют правки в текущем браузере. Для публикации общего каталога предусмотрен перенос JSON в `mastery-data.js`. Схема и полный порядок работы: [MASTERY-CATALOG.md](MASTERY-CATALOG.md).

Автоматические проверки нового раздела:

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test
```

Проверяются маршруты, фильтры, две отдельные технологии Blender/Aseprite, создание и перенос курсов между ветками, сохранение, импорт/экспорт, защита связей и мобильные экраны.


## Курсы и уроки

Карточка курса открывает титульную страницу с описанием, результатами обучения, требованиями и программой. «Поступить на курс» открывает уроки; «Продолжить обучение» возвращает к последнему месту. В режиме администратора «Редактировать уроки» открывает редактор из репозитория `redactor`, перенесённый в `course-player/`.

Материалы каждого курса хранятся в его `curriculum` и входят в экспорт JSON каталога. Ответы, прогресс и локальная запись на курс сохраняются отдельно в браузере. Старая версия курса из самостоятельного редактора переносится через «Экспорт курса» → импорт JSON во встроенном редакторе выбранного курса. Подробности и ограничения — в [MASTERY-CATALOG.md](MASTERY-CATALOG.md).

Основные курсы поддерживают сетку и список, включая перетаскивание в обоих видах. В сетке карточки такие же крупные, как у прикладных курсов; переход выполняется по всей карточке без отдельной стрелки. Три вводных урока Godot уже доступны в курсе «Godot с нуля».

## Ежедневные задания

Галочки ставятся автоматически после выполнения условий. Вход на сайт приносит 25 XP и 5 кристаллов; завершение всех шагов нового урока в режиме ученика — 50 XP и 10 кристаллов. Открытие урока, отдельный правильный ответ, повторное открытие уже пройденного урока и сохранение в редакторе награды не дают.

Каждое задание оплачивается один раз за календарный день по часовому поясу браузера. В полночь статусы обновляются; баланс сохраняется. Размеры наград заданы в `DailyQuests.definitions` в `daily-quests.js`. Журнал начислений `indieforge.daily-quests.v1` хранится отдельно от каталога и ученических ответов. Награда и запись о выполнении сохраняются одним действием; Web Locks синхронизируют вкладки. При недоступном хранилище начисление не показывается, отложенные события повторяются при следующей проверке в открытой вкладке.

Опыт, кристаллы, уровень и полоса прогресса во всех местах используют этот журнал. Сохранены прежние стартовые значения макета: 3320 XP и 1240 кристаллов; один уровень соответствует 600 XP. Это локальные данные браузера, без серверного аккаунта и синхронизации между устройствами.

Песочница и рабочее пространство проектов ещё не созданы. Для их подключения подготовлены обработчики, которые нужно вызывать **после успешной проверки / сохранения**, а не по нажатию на карточку:

```js
// Успешно принятое решение с минимум 20 непустыми строками: 50 XP, 10 кристаллов.
await DailyQuests.recordCodeSubmission({id: submission.id, code: submission.code, accepted: true});
// Сохранённый непустой проект с изменениями: 75 XP, 15 кристаллов.
await DailyQuests.recordProjectSave({id: project.id, previous: oldContent, content: savedContent});
```

Повторные вызовы обработчиков в тот же день не увеличивают награду. Пока эти разделы являются заглушками, задания «Написать 20 строк кода» и «Поработать над проектом» остаются невыполненными. JSON каталога не содержит балансы и журнал наград. При подключении серверных аккаунтов проверку выполнения и начисление нужно перенести в серверную транзакцию.

Проверки: `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test -- tests/daily-quests.spec.cjs`.

## Изображения

Семь растровых иллюстраций главной страницы переведены из PNG в WebP Lossless без изменения размеров. После декодирования проверено полное совпадение пикселей каждого файла с оригиналом. Общий размер этих изображений уменьшился с 11 898 658 до 8 576 060 байт: экономия 3 322 598 байт (27,92%). Исходные PNG доступны в истории Git. Векторные SVG сохранены, чтобы не терять чёткость при масштабировании. Скриншоты в `verification/` — материалы проверки, сайт их не загружает.

Для «Древа мастерства» подготовлены 98 отдельных иллюстраций: 13 технологий и 85 курсов. Обложки хранятся в `assets/mastery/technologies/` и `assets/mastery/courses/` в WebP без потерь. Старые стандартные обложки в локальном каталоге обновляются автоматически; собственные изображения и содержимое курсов сохраняются.
