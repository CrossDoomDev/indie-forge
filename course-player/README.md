# Встроенный редактор курса

Перенесён из репозитория `CrossDoomDev/redactor`, исходная версия `3fb779f`.

`app.js`, `course-model.js`, `reorder.js`, `step-inline.js` и стили сохраняют существующие инструменты редактора: модули, уроки, шаги, задания, HTML, форматирование, изображения, GDScript, импорт и экспорт. Исходный репозиторий не менялся.

Платформенная интеграция:

- `platform-bridge.js` получает один курс от родительской страницы через `CourseWorkspace.connect` и направляет сохранение обратно в каталог. Прямое открытие этой внутренней HTML-страницы возвращает в древо мастерства.
- `app.js` использует переданный проект вместо общего ключа `kursograf.course-editor.v1`; встроенный редактор этот старый ключ не читает и не записывает.
- В режиме ученика сохраняются только ответы, прогресс и текущая позиция. В режиме автора — материалы выбранного курса. Последние правки сохраняются перед выходом и сменой режима; при ошибке записи смена режима блокируется, чтобы сохранить правки в открытом редакторе. Доступен экспорт резервной копии JSON.
- `platform.css` объединяет редактор с навигацией платформы; переключатель видов находится снаружи. CSS редактора изолирован от каталога отдельным документом.
- HTML импортированных уроков проходит существующий allowlist-санитайзер перед отображением; просмотр конспекта остаётся в sandboxed iframe.

Открывайте уроки через адрес платформы `#/mastery/{technologyId}/{branch}/{courseId}/learn/{lessonId}`. Отдельный редактор поддерживает импорт резервной копии старого проекта; перед импортом выберите нужный курс в каталоге.
